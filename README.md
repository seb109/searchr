# searchr
searchr is a learn-as-you-do project.
What is searchr?
searchr is a small project that i'm aiming to build. It is a facial feature recognition and landmark or vector; extraction technology which finds the user in a folder full of images when provided with a small set of base images of the user from where it extracts the required points or vectors and then finds the user.
why am i building it?
often times i've spent more time than i should have finding photos of myself in google drive folder of an event just to end up with 2-3 photos. at that moment i thought of building search. I for one don't think searchr would be a big million dollar startup or anything, its just a tool that i;m building because i need it and if in the future some other person also needs searchr it should be in a good shareable and accessable form.
